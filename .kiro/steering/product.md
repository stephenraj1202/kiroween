# Product: Necro-Compiler

Kiroween 2026, **Resurrection** category. A static web app that raises dead
Visual Basic 6 `.frm` forms in the browser: drop a form, see it run.

- Audience: people holding legacy VB6 forms who cannot run them anymore.
- Theme: a haunted crypt UI around a Win95-style window. Files are "dead forms",
  loading is "resurrection", failures are "this spirit cannot be raised".
- No backend. Everything runs client-side.
- Only original sample forms and royalty-free or self-made assets.
- Never add `.kiro/` to `.gitignore` (hackathon requirement).
