# Necro-Compiler

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Raise dead Visual Basic 6 forms from the grave. Drop a `.frm` file and it runs in your browser.
Built with Kiro for Kiroween 2026 (Resurrection category).

## Run locally

```
npm install
npm run dev
npm test
```

## Status

Under construction. See `.kiro/specs` for the specs and `docs/kiro-usage.md` for how Kiro was used.
